Configuração de E-mails Transacionais (Resend)

O Resend é o serviço utilizado pelo sistema 2Bags2rent para o envio de e-mails de confirmação e atualizações de pedidos para os clientes. Siga o passo a passo abaixo para configurá-lo.

1 Criar uma conta no Resend

Acesse o site resend.com e crie uma conta gratuita. O plano grátis permite o envio de até 3.000 e-mails por mês, o que é suficiente para a maioria das lojas iniciantes.

2 Adicionar seu Domínio

Para enviar e-mails de forma profissional (sem cair na caixa de spam), você precisa registrar o seu domínio (ex: 2bags2rent.com.br).

  • No painel do Resend, vá no menu esquerdo e clique em Domains.
  • Clique no botão Add Domain.
  • Digite o seu domínio e região.
  • O Resend irá gerar alguns registros DNS (geralmente DKIM, SPF, TXT etc). Copie esses registros e adicione nas configurações de DNS onde o seu domínio está hospedado (ex: Registro.br, Cloudflare, HostGator).
  • Após adicionar as entradas DNS no seu provedor, clique no botão Verify no Resend e aguarde o domínio ficar com o status esverdeado "Verified".

3 Gerar a Chave da API (API Key)

A API Key é a senha que nosso sistema usará para disparar os e-mails.

  • No painel do Resend, clique em API Keys no menu à esquerda.
  • Clique em Create API Key.
  • Dê um nome para a chave (Ex: Site 2Bags2rent).
  • Deixe a permissão como Full Access.
  • Copie a chave gerada (ela começa com re_...). Atenção: Guarde bem essa chave, pois ela não será exibida novamente.
Pegue a chave recém-copiada e cole no campo API Key na tela de Configurações Administrativas do site.

4 Utilizando as Tags Dinâmicas

Ao redigir o corpo dos seus e-mails (no campo HTML do sistema), você pode usar "Tags" para inserir informações dinâmicas que serão trocadas pelos dados do pedido na hora do disparo. Nosso sistema já vem preenchido com um Template Padrão, mas sinta-se livre para editá-lo.

Tag O que representa Exemplo de Saída
{{customer_name}} Nome do cliente João da Silva
{{order_id}} Identificador (código) do pedido #PED-876F9A2
{{total_price}} Valor total do pedido formatado (R$) R$ 299,50
{{financial_status}} Status financeiro em português Pago / Pendente
{{shipping_address_name}} Nome preenchido no endereço de entrega Maria da Silva
{{items_list}} Uma tabela HTML pronta listando todos os itens do pedido com valores (Gera as linhas da tabela de produtos automaticamente)
{{created_at}} Data e hora em que o pedido foi feito 12/04/2026, 17:00

5 Testando a Configuração

Após preencher no painel a sua Chave da API, o nome e e-mail do remente (que deve obrigatoriamente usar o domínio "Verified" do passo 2), volte ao seu painel Administrativo do 2Bags2rent e clique em Enviar E-mail de Teste. Se tiver configurado corretamente, um aviso verde aparecerá na tela e você receberá um e-mail de prova na sua caixa de entrada.
